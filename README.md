# Живой платформер

Пустой 2D-платформер, который меняется прямо во время игры. Пишешь в чат или говоришь в микрофон, например «добавь врага», «сделай ночь» или «двойной прыжок». Claude пишет кусок JavaScript, игра сразу его выполняет, без перезагрузки и без потери состояния. Обычно это занимает 2–3 секунды на Haiku и 4–5 секунд на Sonnet.

## Что нужно

- [Node.js](https://nodejs.org) 18 или новее, внешних зависимостей нет
- Claude Code CLI с выполненным входом (работает от подписки Claude, API-ключ не нужен)
- Chrome или Edge, если хочешь голосовой ввод

## Установка и запуск

```powershell
npm.cmd install -g @anthropic-ai/claude-code   # если CLI ещё нет
claude auth login                               # один раз; если PowerShell не находит claude:
                                                # & "$env:APPDATA\npm\claude.cmd" auth login
node server.js
```

Открой http://localhost:5173.

## Управление

| Что | Как |
|---|---|
| Ходить / прыгать | стрелки или WASD, Space |
| Написать команду | Enter, затем текст, затем Enter |
| Голос | клавиша `` ` `` или кнопка 🎤. Говоришь фразу, она отправляется сама |
| Сменить модель | список внизу или команда `/model sonnet` в чате |
| Отменить последнее изменение | ↶ отмена |
| Начать с пустого мира | ⟲ сброс. Заодно стирает память Claude |

## Модели

В списке есть `haiku`, `sonnet` и `opus`. Все запускаются с `--effort low`, потому что здесь важнее скорость. По умолчанию стоит `haiku`, начальную модель можно задать так: `$env:GAME_MODEL='sonnet'; node server.js`.

При смене модели сервер перезапускает процесс Claude и передаёт новой модели код всех уже применённых изменений, поэтому она продолжает с того же места.

## Как это устроено

```
браузер ── POST /ask ──▶ server.js ── stream-json ──▶ один постоянный процесс `claude -p`
   ▲                                                         │
   └──────────── JS-патч ◀───────────────────────────────────┘
```

- **[server.js](server.js)** раздаёт игру и держит один процесс Claude CLI в режиме `stream-json`. Поэтому задержка запуска CLI бывает один раз при старте, сервер прогревает его сам. Запросы обрабатываются по очереди.
- **[prompt.md](prompt.md)** — системный промпт: формат ответа и полное описание API игры. Чем точнее он описывает движок, тем точнее патчи.
- **[public/engine.js](public/engine.js)** — движок: физика, камера, сущности, частицы, звук и объект `game` с хуками `game.on('update' | 'draw' | 'ui' | 'jump' | ...)`.
- **[public/live.js](public/live.js)** — чат, голос (Web Speech API, `ru-RU`), выполнение патчей, отмена, смена модели.

Каждый патч — это тело функции `(game, ctx) => {...}`, оно выполняется один раз и вешает хуки или меняет свойства мира. Патчи хранятся по порядку в `localStorage`. Отмена и перезагрузка страницы пересоздают мир с нуля и проигрывают патчи заново.

### Если код сломается

- Ошибка при выполнении патча или внутри хука ловится, сломанный хук снимается, игра продолжает работать.
- Ошибка показывается в чате, и Claude автоматически просит исправление, максимум два раза подряд.
- Если мод испортил главный цикл (`game.update` или `game.draw`), движок возвращает свои исходные функции.

## Ограничения

- Игра локальная и для одного игрока, в браузере выполняется код, который написала модель.
- Чем длиннее сессия, тем больше история у Claude и тем медленнее ответы. Помогает «сброс».
- Голосовой ввод работает только в Chrome и Edge.
