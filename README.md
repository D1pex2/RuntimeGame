# Живой платформер

Пустой 2D-платформер, который меняется прямо во время игры. Пишешь в чат или говоришь в микрофон, например «добавь врага», «сделай ночь» или «двойной прыжок». ИИ пишет кусок JavaScript, игра сразу его выполняет, без перезагрузки и без потери состояния. Код может писать **Claude** (Claude Code CLI) или **Codex** (Codex CLI), переключаются они прямо в игре.

Ответы в моих замерах:

| ИИ | Время ответа |
|---|---|
| Claude Haiku | 1.6–2.5 с |
| Claude Sonnet | 4–5 с |
| Codex gpt-6.1-sol | 4–5 с |
| Codex gpt-6.1-sol ⚡ fast | 3.7 с |

## Что нужно

- [Node.js](https://nodejs.org) 18 или новее, внешних зависимостей нет
- Хотя бы один CLI с выполненным входом, API-ключи не нужны:
  - Claude Code CLI (подписка Claude)
  - Codex CLI (аккаунт ChatGPT)
- Chrome или Edge, если хочешь голосовой ввод

## Установка и запуск

```powershell
npm.cmd install -g @anthropic-ai/claude-code   # Claude CLI
npm.cmd install -g @openai/codex               # Codex CLI
& "$env:APPDATA\npm\claude.cmd" auth login      # вход в Claude, один раз
& "$env:APPDATA\npm\codex.cmd" login            # вход в Codex, один раз
node server.js                                  # или: node server.js 5174 — на другом порту
```

Открой http://localhost:5173.

`npm.cmd` и полный путь к `.cmd` нужны, если PowerShell запрещает скрипты или папка npm не прописана в PATH. Сервер сам ищет CLI в `%APPDATA%\npm`.

## Управление

| Что | Как |
|---|---|
| Ходить / прыгать | стрелки или WASD, Space |
| Написать команду | Enter, затем текст, затем Enter |
| Голос | клавиша `` ` `` или кнопка 🎤. Говоришь фразу, она отправляется сама |
| Сменить ИИ / модель | списки внизу, или в чате `/engine codex`, `/model sonnet`, `/model gpt-6-luna` |
| Ускорение Codex | галочка ⚡ fast, или в чате `/fast on` / `/fast off` |
| Отменить последнее изменение | ↶ отмена |
| Начать с пустого мира | ⟲ сброс. Заодно стирает память ИИ |
| Сохранить | 💾 сохранить, потом ввести имя |
| Загрузить | 📂 загрузить, потом клик по имени. ⬇ скачивает весь код сейва одним `.js`, 🗑 удаляет сейв |

## ИИ и модели

У всех моделей стоит effort low (низкий уровень рассуждений), потому что здесь важнее скорость.

- **Claude:** `haiku` (по умолчанию), `sonnet`, `opus`. Fable в список не входит: на этом аккаунте для него нужны платные кредиты.
- **Codex:** список берётся у самого Codex при старте (`model/list`). Сейчас это gpt-6.1-sol, gpt-6-astra, gpt-6-sol, gpt-6-luna, gpt-5.6-sol, gpt-5.6-terra, gpt-5.6-luna.
- **⚡ fast:** включает у Codex service tier `priority`. По данным Codex это в 1.5–2 раза быстрее, но лимит подписки расходуется сильнее. У Claude такого переключателя нет.

Что происходит при переключении:
- **Модель или fast у Codex** меняются прямо в текущем диалоге, память сохраняется.
- **Модель Claude или смена Claude ↔ Codex** перезапускают процесс ИИ. Новый процесс получает код всех уже применённых изменений и продолжает с того же места.

С каким ИИ стартовать, можно задать переменными окружения: `$env:GAME_ENGINE='codex'; $env:GAME_MODEL='gpt-6-luna'; $env:GAME_FAST='1'; node server.js`.

## Сейвы

Сейв — это файл `saves/<имя>.json`: код всех изменений по порядку, плюс движок и модель, на которых он сделан. При загрузке мир пересоздаётся из этого кода, и ИИ получает его как контекст. Папка `saves/` не попадает в git.

Текущие изменения ещё и автоматически хранятся в браузере (`localStorage`), поэтому переживают перезагрузку страницы. Если перезапустился сервер, страница при открытии сама передаст ему код, и память ИИ не потеряется.

## Как это устроено

```
браузер ── POST /ask ──▶ server.js ──▶ один постоянный процесс ИИ:
   ▲                                    • claude -p (stream-json)
   │                                    • codex app-server (JSON-RPC по stdio)
   └──────────── JS-патч ◀──────────────┘
```

- **[server.js](server.js)** раздаёт игру и держит один постоянный процесс ИИ. Задержка запуска CLI бывает только при старте, и сервер прогревает процесс сам. Запросы обрабатываются по очереди. Codex получает `prompt.md` вместо своего стандартного системного промпта (`baseInstructions`), инструментов и прав на запись у него нет.
- **[prompt.md](prompt.md)** — системный промпт: формат ответа и полное описание API игры. Чем точнее он описывает движок, тем точнее патчи.
- **[public/engine.js](public/engine.js)** — движок: физика, камера, сущности, частицы, звук и объект `game` с хуками `game.on('update' | 'draw' | 'ui' | 'jump' | ...)`.
- **[public/net.js](public/net.js)** — мультиплеер: WebSocket к серверу, состояние своего персонажа, снимки мира от хоста, общие изменения.
- **[public/live.js](public/live.js)** — чат, голос (Web Speech API, `ru-RU`), выполнение патчей, отмена, смена модели.

Каждый патч — это тело функции `(game, ctx) => {...}`, оно выполняется один раз и вешает хуки или меняет свойства мира. Патчи хранятся по порядку в `localStorage`. Отмена и перезагрузка страницы пересоздают мир с нуля и проигрывают патчи заново.

### Если код сломается

- Ошибка при выполнении патча или внутри хука ловится, сломанный хук снимается, игра продолжает работать.
- Ошибка показывается в чате, и Claude автоматически просит исправление, максимум два раза подряд.
- Если мод испортил главный цикл (`game.update` или `game.draw`), движок возвращает свои исходные функции.

## Мультиплеер по локальной сети

Друзья в той же сети открывают адрес, который сервер печатает при старте:

```
Для друзей в этой сети: http://10.22.3.94:5173   с голосом: https://10.22.3.94:5443
```

- **HTTP** работает сразу, но голос у друзей не заработает: Chrome даёт микрофон только по HTTPS или на localhost.
- **HTTPS** (порт = HTTP + 270) с самоподписанным сертификатом. Сервер создаёт его сам в `certs/` через `openssl` (он есть в Git for Windows). Браузер один раз предупредит о небезопасном сайте: «Дополнительно» → «Перейти на сайт».
- При первом входе игра спрашивает имя. Его можно передать и в адресе: `?name=Вася`.

Что общее:
- **Изменения кода.** Кто бы ни попросил, голосом или в чате, патч применяется у всех. Отмена, сброс и загрузка сейва тоже действуют на всех. Все видят, кто что попросил.
- **Мир.** Его считает **хост**, первый вошедший браузер: враги, монетки, пули, `game.state` (счёт). Хост рассылает снимок мира 30 раз в секунду. У остальных чужие персонажи и объекты показываются с задержкой 0.1 с и плавно тянутся между снимками, поэтому не дёргаются. Если хост вышел, хостом становится следующий игрок.
- **Персонажи.** Каждый двигает своего сам, остальные видят его с именем над головой. Касания (урон, подбор, отскок) решает хост и отправляет игроку изменения.
- **Нажатия.** Обработчики `game.on('key' | 'click')` выполняет хост от имени нажавшего игрока, поэтому пули друга видят все.

Если друзья не могут подключиться:
- **Брандмауэр Windows.** Входящие подключения к Node, скорее всего, заблокированы: сеть помечена как «Общедоступная», правил для Node нет. Разреши порты в PowerShell **от администратора**:
  ```powershell
  New-NetFirewallRule -DisplayName "RuntimeGame" -Direction Inbound -Protocol TCP -LocalPort 5173,5443 -Action Allow
  ```
  Удалить это правило потом можно так: `Remove-NetFirewallRule -DisplayName "RuntimeGame"`.
- **VPN** на компе с сервером может перехватывать локальный трафик. Если не пускает, выключи VPN на время игры.
- **Одна сеть.** Друзья должны быть в той же сети, что и комп. Если комп выходит в интернет через телефон по USB, устройства на точке доступа этого телефона видят комп не на всех телефонах.

## Ограничения

- В браузере каждого игрока выполняется код, который написала модель по чьей-то просьбе. Играй с теми, кому доверяешь.
- У клиентов объекты, которые хост создал во время игры, рисуются по образцу, если клиент уже видел такой объект с тем же `tag`. Иначе это просто цветной прямоугольник.
- Хуки `update`, которые создают объекты по `game.pressed()`, срабатывают только у хоста. Промпт просит ИИ делать такие действия через `game.on('key')`.
- Чем длиннее сессия, тем больше история у ИИ и тем медленнее ответы: после десятка больших изменений Claude отвечал уже по 15–37 с. Помогает «сброс» или сохранить, сбросить и загрузить сейв. Загрузка передаёт только код, без истории разговора.
- Физика прямоугольная: склоны и горки ИИ рисует, но скользить по ним персонаж не может.
- Голосовой ввод работает только в Chrome и Edge.
